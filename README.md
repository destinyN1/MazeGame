# MazeGame

> **Note:** This was made in college to practise basic programming skills. It is not
> functional in any proper way and will not be updated again.

A small C++ console program that builds a grid, either a size you choose or a random one, as a
starting point for generating a maze. The maze generation itself was never finished.

## Files

- `MazeGame.cpp`: the source code
- `MazeGameFunc.exe`: a Windows build of the program
